# Фактические ограничения

1. Человеческих меток нет. Превосходство над baseline и бизнес-эффект не доказаны. Владелец сообщил, что пока не может размечать; это явно сохранено в статусе.
2. После извлечения подтверждённых канонических ссылок из публичных статей у **507 из 1473** нормализованных материалов URL остаётся неизвестным. У 510 строк до дедупликации. Полная проверка доступности HTTP не проведена. Нельзя называть все ссылки проверенными.
3. Пользовательская история исходной платформы не привязана к браузеру. Записи обучения и оценки изучены по структуре и агрегатам. В продукте работают собственные события приложения, не реальные page views.
4. Прогресс связан с cookie браузера и БД. После удаления cookie доступ к старой сессии теряется. Это локальный демо-механизм, а не полноценная авторизация или синхронизация устройств.
5. У FULL отсутствуют подтверждённые сложность и стадия материала. Они nullable. У синтетических материалов эти признаки заданы явно для демонстрации, а не извлечены из реального источника.
6. Публикация фильтруется по реальным статусам и закрытости, доступ консервативно определяется из типов/подписок/цены. Не все бизнес-смыслы полей подтверждены владельцем платформы. Неизвестное остаётся unknown.
7. E5 — опциональная локальная модель. Пороги инженерные и ещё не валидированы независимыми экспертами. Косинусное сходство не равно вероятности релевантности. При отсутствии весов/зависимостей работает лексический fallback.
8. Для первой сборки нужны публичные Docker/npm/PyPI-реестры, для подготовки E5 — Hugging Face. Проверка на полностью отключённом сетевом адаптере не проводилась. Закрытые тексты не передаются в AI API.
9. Профили, события и маршруты не являются банковской/налоговой консультацией. Результат бизнеса не гарантируется. Покупки и интеграция аналитики платформы не реализованы.
10. CI реально прошёл на GitHub, в том числе run 43238234280. Итог каждого нового release commit проверяется отдельно. Публичный сайт, доступ жюри и отправка не выполнялись.
11. PDF для репетиции состоит из проверенных рендеров слайдов; редактируемый исходник — отдельный PPTX. Прямой PDF-экспорт рабочего инструмента был недоступен. PowerPoint вручную не открывался.
12. Полная нагрузочная проверка, аудит доступности по WCAG и независимый security audit не проводились. Проверены основные сценарии desktop/mobile и явные ограничения приватности.
