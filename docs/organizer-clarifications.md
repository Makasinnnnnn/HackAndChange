## Решение по LLM

PDF допускает правила, ML, LLM или сочетание. В экспорте не найдено требования обязательно подключить генеративную LLM. Локальная E5 уже обеспечивает нейросетевой поиск по смыслу, но не генерирует ответы; её превосходство над baseline пока не доказано независимой разметкой.

Приоритет остаётся у качества на FULL, достоверных ссылок, истории и воспроизводимых проверок. Возможная следующая итерация LLM — извлечение структурированной задачи и одно полезное уточнение. Материалы выбираются только из каталога, поля проверяются, есть локальный fallback. Такая итерация пока не реализована и не обещается как готовая функция.

## Открытая проверка цены

Импорт пока использует прежние эвристики: тип доступа, подписочные связи и положительную цену тарифа. Новое правило NULL ещё не применено к каталогу. Нужно отдельно проверить конфликтующие признаки Courses, отделить цену от доступа и добавить регрессионную проверку. Старые агрегаты каталога относятся к предыдущей нормализации; не выдавать их за результат нового правила.
