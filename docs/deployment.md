# Локальное развёртывание

Поддерживаемая демонстрация: Docker Desktop, Linux containers, Compose v2, Windows. Корень проекта — HackAndChange. Не выполнять команды из соседнего кредитного проекта.

`docker compose up --build` запускает DEMO без внешних ключей. По умолчанию лексическое ранжирование. Веб-порт 3080 доступен только с локальной машины. База и API не публикуют порты на хост. `.env.example` содержит только локальные демонстрационные настройки.

Опциональные файлы: `compose.full.yaml` подключает приватный нормализованный каталог read-only; `compose.semantic.yaml` подключает локальные публичные веса и расширенные зависимости; `compose.evaluation.yaml` подключает заранее рассчитанный агрегатный отчёт DEMO. Подробные команды в README. Не включать FULL на публичном хостинге с данными кейса.

Пароль исходной БД не требуется: аудит проходит в отдельном контейнере без сети. Доверенная локальная аутентификация допускается только внутри этого изолированного контейнера. Никогда не применять его конфигурацию к общедоступной БД.

При старте Docker Desktop могут автоматически возобновиться контейнеры других проектов. Их не выключать и не очищать. Для теста чистого запуска используется отдельный Compose project с отдельным портом/томом. Основной том прогресса не удаляется.

Перед будущим публичным развёртыванием нужны отдельное решение владельца, только разрешённые данные, HTTPS, `COOKIE_SECURE=true`, отключение открытой диагностики, настройка доступа и отдельные секреты. Текущая конфигурация ориентирована на localhost.
