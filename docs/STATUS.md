# Состояние проекта

Обновлено: 12.11.2026. Этап: работающий локальный MVP, оценка и подготовка защиты.

**Работает и проверено:** Next.js, FastAPI, PostgreSQL, маршруты, объяснения, cold start, необязательная анкета, обратная связь и прогресс, каталог, реальное сравнение baseline. DEMO — 36 авторских материалов. FULL — 1473 материала после фильтров/дедупликации реальных метаданных. Изолированное восстановление подтвердило 62 таблицы и 102128 строк. Проверена настоящая локальная E5 ONNX и fallback.

**Проверки:** 37 Python-тестов с локальными весами, 6 браузерных E2E на desktop/mobile, typecheck, build, lint, API smoke в DEMO/FULL, перезапуск с сохранением прогресса. Отдельный чистый стек поднят с пустым томом и полностью удалён после проверки. Основной том сохранён. Подготовлены CI, A/B-план, сценарий защиты и 9 слайдов для репетиции.

**Пока не готово:** человеческая оценка и доказательство улучшения рекомендаций, подтверждение 507 отсутствующих URL, полная HTTP-проверка ссылок, привязка реальной пользовательской истории, название/состав команды для финального комплекта. Публичный сайт, push в GitHub и отправка не выполнялись. Презентация честно помечена версией для репетиции.

**Следующий приоритет:** независимая проверка релевантности и оставшихся ссылок. Владелец 12.11.2026 поручил продолжать техническую работу, сообщил, что пока не может размечать кандидатов. Актуальный пул E5: `.private/evaluation-full-e5-v1/`, 32 профиля, 412 пар, ноль человеческих меток. Никакие цифры качества или роста конверсии не выдуманы.
