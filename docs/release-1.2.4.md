# Альфа-Маршрут 1.2.4

Редизайн интерфейса, модульный pipeline v7, прямые переходы к семи форматам материалов, отдельно доступное описание и обозначение платного доступа. Неизвестный URL не подменяется фиктивным. Источник ограничен официальным HTTPS-доменом без учётных данных.

Лексический режим работает без внешних AI API. E5 и Qwen подключаются локально; генеративная модель предлагает формулировку с явным принятием. Собственный feedback и импорт завершённых курсов влияют на персональную выдачу; данные исходных пользователей не присваиваются посетителю.

Проверки:182 Python с реальной E5,46 desktop/mobile E2E, production Docker, DEMO/FULL smoke и persistence. Подробности — [verification.md](verification.md). Независимые human-метрики и бизнес-эффект отсутствуют.

Комплект сдачи очищен от внутренних инструкций и рабочих журналов; включает полный исходный код, тесты, документацию и PDF/PPTX. Запуск — [START_HERE_JURY.md](../START_HERE_JURY.md). Runtime остаётся 1.2.4; опубликованные исторические теги не заменяются.
