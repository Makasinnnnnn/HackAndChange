# Альфа-Маршрут 1.2.4

Объединены работы участников: редизайн PR #1, аудит/CLI PR #2 и переходы к материалам PR #3. История коммитов и прежние релизы сохранены. [Разбор Markdown и решений интеграции](integration-2026-11-16.md).

Материалы Альфа-Курса открываются напрямую в новой вкладке, описание доступно отдельной кнопкой. Учтены семь форматов, платный доступ, отсутствие URL, desktop/mobile и возврат фокуса. Сервер ограничивает ссылки официальным HTTPS-доменом без учётных данных. Новый импорт формирует 1476 материалов; заполненные адреса не объявляются проверенными HTTP-ответами.

Исправлен добавленный CSV-оценщик: пустая выдача не исчезает из расчёта, неразмеченное не считается отрицательным, Precision@k имеет фиксированный знаменатель, IDCG использует релевантный пул. Подробные отчёты остаются приватными. Исторические гипотезы аудита не ослабляют проверенные фильтры алгоритма.

Проверки: **182 pytest с настоящей E5**, **46 desktop/mobile E2E**, Ruff, TypeScript, production Docker; DEMO/FULL по 8 smoke-проверок и сохранение прогресса после restart DB/API. На новом FULL повторены 150+120 регрессионных запросов: просмотрены четыре изменения порядка/состава/формулировки; они не показали новой смысловой ошибки по оценке агента. Это не независимый экспертный тест.

Подготовлен новый совместимый human-пул: 32 профиля / 51 пара, человеческих меток пока 0, metrics=null. Превосходство над baseline и рост конверсии не доказаны. Все страницы внешней платформы не проверены.

Запуск: `docker compose up --build`, http://localhost:3080. DEMO содержит 36 авторских примеров без дампа, моделей и API-ключей. FULL/E5/Qwen подключаются локально по README. ZIP содержит публичный код, документацию и обновлённые PDF/PPTX. Файлы `alfa-route-1.2.*` содержат версию **1.2.4**.
