# Рутинные задачи для бесплатного помощника

Передавать только описание продукта, собственный публичный код и синтетические fixtures. Дамп, реальные карточки, платные тексты, пользовательские события, IP, токены и .private не передавать. Результат помощника проверяется основным разработчиком.

Проверено: OpenCode 1.14.48 установлен. Список моделей содержит free-варианты. По [документации провайдера](https://opencode.ai/docs/console/models/) DeepSeek V4.1 Flash Free заявлен бесплатным на ограниченный период; условия нужно перепроверять перед новым использованием.

12.11 выполнена попытка `opencode run --pure` с явно выбранной free-моделью, запретом инструментов и текстовым описанием продукта в отдельной временной папке. Ответ не появился, запуск остановлен. Нельзя утверждать, что помощник выполнил ревью. На платную модель переключения не было. Код и закрытые данные ему не передавались.

Подходящие задания:

- Написать 8 ручных проверок клавиатуры, ошибок, сессий и сохранения прогресса по публичному описанию.
- Проверить короткую инструкцию запуска на двусмысленные формулировки, не заявляя фактический запуск.
- Предложить более понятные подписи к существующим ошибкам без изменения смысла и без выдуманных функций.

Готовый безопасный текст задания:

> Работай только с этим описанием, не используй инструменты, не читай файлы и не выполняй команды. Предложи 8 ручных QA-сценариев на русском: действие и ожидаемый результат. Продукт — локальный рекомендатель образовательных материалов для предпринимателей, необязательная анкета, ввод до 1500 символов, feedback и cookie-сессия, синтетический DEMO, реальное сравнение baseline. Сосредоточься на клавиатуре, ошибках, устаревших ответах, изоляции сессий и сохранении прогресса. Не утверждай, что проверил приложение.
