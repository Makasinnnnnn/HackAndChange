# Альфа-Маршрут 1.1.0

Технически подготовленный конкурсный комплект, 13 ноября 2026.

- Добавлен явный импорт истории завершённых курсов, привязанный к текущей сессии; проверяются каталог, типы материалов, уникальность и атомарность.
- Экспорт обезличенного сценария из исходной read-only базы без UserId/ПДн; реальный сценарий из 18 курсов успешно воспроизведён через API.
- Исправлена версия health endpoint и предотвращён ввод задачи до готовности bootstrap.
- Подтверждён чистый Windows Docker-старт опубликованного ZIP 1.0 с новым томом, 8 smoke-проверками и сохранением feedback. Текущий 1.1 также реально собран локально Docker.
- 47 Python-тестов с E5, 10 desktop/mobile E2E, typecheck и Docker production build прошли. CI проверяется для конкретного SHA.
- Обновлены девять слайдов: output/presentation/alfa-route-1.1.pdf и PPTX, ссылка на репозиторий на первом слайде. Никаких придуманных показателей качества.

Известные внешние границы: человеческая разметка отсутствует, превосходство над baseline не доказано; 507 URL неизвестны, HTTP-проверка сайта останавливается на недоверенном TLS. Нельзя признать все ссылки проверенными. Дамп, реальные каталоги, история, веса и ключи в архив не входят. Внедрение авторизации/платежей и публичный деплой не входят в локальный конкурсный прототип. Отправка организаторам выполняется участником по его решению.
