# Исходные данные и нормализация

Источник — предоставленная организаторами выгрузка Альфа-Курса. В публичном репозитории только агрегаты и код обработки; дамп, полный JSON, реальные подробные выдачи и история остаются локально.

## Восстановление

Проверенный исходный архив:19 675 929 байт, CUSTOM/PGDMP1.16, pg_dump17.6, исходный PostgreSQL16.15. pg_restore16 отказал с unsupported version; восстановление PostgreSQL18 прошло с exit-on-error/single-transaction/no-owner/no-privileges. Используется отдельный аудиторский контейнер с network=none, без опубликованных портов, исходный файл read-only. БД прогресса приложения отдельная.

Фактическая схема:62 таблицы,1 представление,102128 строк;205 индексов,62 первичных ключа,70 внешних ключей. Обработаны реальные полиморфные связи метаданных; дополнительные описания другой схемы не подменяют источник.

## Правила импорта

- Только опубликованные, не удалённые и не закрытые сущности. Перед индексацией проверяется provenance и выполняется детерминированная дедупликация.
- Courses.Cost=NULL означает цену 0, но не отменяет подписочный доступ. Правило не переносится на прочие сущности; тариф подписки не подменяет индивидуальную цену материала.
- Для статей бесплатность определяется типом доступа; IsPublic — отдельный редакторский признак. Неизвестное не становится бесплатным.
- Тела платных уроков не читаются и не публикуются. Разрешены короткие метаданные; платное описание ограничено 180 символами. Извлечение URL из бесплатных опубликованных блоков выполняется локально без сохранения тел.
- Исходные пользовательские записи не назначаются посетителю. Импорт завершённых курсов — явный отдельный сценарий текущей cookie-сессии.
- Неизвестные сложность/стадия не выдумываются. Краткие описания не гарантируют покрытия каждой практической бизнес-задачи.

Точные команды и ожидаемые файлы — раздел 6 [инструкции жюри](../START_HERE_JURY.md). Повторное восстановление/импорт не требуется для обычного DEMO.
