# Источники материалов

В FULL «Открыть на Альфа-Курсе» — HTTPS-ссылка в новой вкладке с noopener/noreferrer; «Подробнее» показывает краткое описание. Платный/подписочный доступ обозначается, покупка выполняется на исходной платформе. DEMO содержит авторские примеры без внешней страницы. Небезопасный или неизвестный URL не заменяется выдуманным адресом.

Сервер допускает у organizer только `kurs.alfabank.ru`, HTTPS, стандартный порт, отсутствие любых учётных данных и некорректных управляющих символов. Импорт использует исходный абсолютный адрес, локально извлечённый канонический URL либо slug в подтверждённом маршруте.

| Тип | Префикс |
|---|---|
| article | articles |
| course | courses |
| document | documents |
| webinar | webinars |
| podcast | podcasts |
| glossary | vocabulary |
| calculator | calculators |

Структура подтверждена публичными страницами платформы 16 ноября 2026, например [курс](https://kurs.alfabank.ru/courses/kak-upravlyat-finansami/), [документ](https://kurs.alfabank.ru/documents/reshenie-ob-odobrenii-krupnoj-sdelki/), [калькулятор](https://kurs.alfabank.ru/calculators/zarplata/). Это не успешная HTTP-проверка всех 1476 строк. TLS на машине показа проверяется отдельно, сертификаты не отключаются.

Порядок read-only восстановления, импорта и извлечения ссылок — раздел 6 [инструкции](../START_HERE_JURY.md). Извлекаются только ссылки из опубликованных бесплатных блоков; тела не сохраняются в каталоге. Новые данные не распространяются публичным архивом.
