# Презентация и запись демонстрации

## Что сдавать

По предоставленным официальным правилам Альфа-трека: **PDF с репозиторием на первом слайде либо ZIP с кодом, документацией и PDF**. Презентация уже включена: [PDF,9 слайдов](../output/presentation/alfa-route-1.2.pdf), [редактируемый PPTX](../output/presentation/alfa-route-1.2.pptx). Внутри указана 1.2.4; имя файла содержит minor-версию 1.2. Делать презентацию с нуля не требуется.

Перед загрузкой просмотрите PDF целиком, проверьте ссылку на репозиторий на первом слайде. При необходимости добавьте название команды и участников в PPTX и экспортируйте обновлённый PDF. Не заменяйте реальные ограничения обещаниями доказанной точности или роста покупок.

**Видео для Альфа-трека не является обязательным требованием.** Правила обязательного видео и coverage>80% в общем сообщении относятся к другому кейсу. Ролик ниже — необязательный резерв показа, если вы хотите его приложить или использовать на защите.

## Подготовка записи

1. Запустите приложение по [точной инструкции](../START_HERE_JURY.md). Сначала проверьте `/api/ready`; для AI-показа также `/api/intent`. Заранее скачайте модели, сборку не включайте в основной ролик.
2. Для публичной записи используйте авторский DEMO. Прямо произнесите, что это 36 синтетических примеров, а реальный каталог подключается отдельно. Исходный дамп, полный реальный каталог, ключи, чужой прогресс и личную переписку в кадр не включайте.
3. Откройте отдельный профиль/окно браузера со свежей тестовой сессией. Не очищайте рабочий PostgreSQL-том. Закройте панели конфигурации и лишние вкладки.
4. Откройте интерфейс на фактически выбранном порту, например http://127.0.0.1:3080. Используйте обычный читаемый масштаб браузера; не уменьшайте страницу до нечитаемого общего плана.
5. Подготовьте запросы из таблицы ниже. Сначала один раз пройдите сценарий без записи и убедитесь, что соответствующие кнопки доступны в выбранном режиме.

## Как записать в Windows11

1. Нажмите **Win+Shift+R** либо откройте «Ножницы» → режим видеозаписи → «Создать».
2. Выделите область с окном браузера, при необходимости включите микрофон, нажмите «Начать».
3. Выполните сценарий. Не переключайтесь в `.env`, приватные файлы или переписку.
4. Остановите запись, сохраните видео, например `alfa-route-demo.mp4`, вне исходников проекта.
5. Откройте сохранённый файл и просмотрите начало, середину и конец; проверьте читаемость интерфейса и звук. Наличие файла ещё не подтверждает успешную запись.

Эти команды относятся к актуальному инструменту Windows11: [официальная инструкция Microsoft](https://support.microsoft.com/en-us/windows/apps/use-snipping-tool-to-capture-screenshots). Если установленная версия «Ножниц» не поддерживает видео, используйте уже имеющуюся программу записи; установка дополнительного рекордера не обязательна для сдачи проекта.

## Точный сценарий на 3–4 минуты

| Время | Действие в интерфейсе | Краткое объяснение |
|---|---|---|
| 0:00–0:20 | Главная, видна маркировка DEMO | «Альфа-Маршрут подбирает обучение под текущую бизнес-задачу. Здесь авторский DEMO, полный каталог подключается локально». |
| 0:20–1:00 | Ввести «Хочу привлечь клиентов в кофейню» → «Построить маршрут»; профиль оставить пустым | «Для старта не нужна обязательная анкета. Подборка может содержать меньше трёх карточек: слабые совпадения не добавляем ради количества». |
| 1:00–1:30 | Показать причину и следующий шаг, открыть пример, закрыть окно | «Объясняем фактически использованный признак. В DEMO это учебный пример; FULL ведёт на официальный источник с обозначением доступа». |
| 1:30–2:00 | Отметить «Изучено» → перестроить → «Мой прогресс» → обновить страницу | «Освоенный материал исключается, прогресс сохраняется в этой браузерной сессии». Если единственная карточка исчезла — это ожидаемый результат исключения. |
| 2:00–2:40 | «Для жюри» → выбрать предпринимателя → «Сравнить алгоритмы» | «Два реальных расчёта на одном каталоге. Baseline без личного профиля, истории и E5; внутренние score не доказывают превосходство». |
| 2:40–3:00 | Вернуться к форме, ввести «Помогите с бизнесом» → построить | «Недостаточно контекста — уточняем задачу, а не показываем случайный маршрут». |
| 3:00–3:40 | Только при подключённом Qwen: «Хочу открыть кофейню и проверить спрос до аренды помещения» → «Уточнить задачу с AI» → просмотреть и явно принять предложение | «Модель помогает с формулировкой, но пользователь принимает её сам. Каталог ранжируется отдельным алгоритмом». |
| Последние 10–20 с | Вернуться к главной или показать титул PDF | «Docker-запуск, код и инструкция приложены. E5/Qwen опциональны. Человеческая оценка релевантности и A/B-эффект ещё не получены». |

Если Qwen выключен, пропустите AI-фрагмент и скажите, что основной режим работает без модели. Если модель вернула unchanged/ошибку, покажите фактический статус и продолжите обычный подбор; не выдавайте результат другого запроса за текущий.

## Проверка перед отправкой

- В чистом ZIP есть `README.md`, `START_HERE_JURY.md`, код, зависимости, Docker и `output/presentation/alfa-route-1.2.pdf`.
- PDF открывается, содержит 9 слайдов и ссылку на репозиторий на первом.
- Локальный адрес 127.0.0.1 не выдаётся за публичный deployment.
- Ролик, если сделан, воспроизводится и не содержит закрытых данных. Он не заменяет обязательный PDF/состав ZIP.
- Видеофайл добавляйте отдельным приложением только если площадка позволяет; исходный репозиторий и компактный ZIP не нужно раздувать записью.
- Комплект отправляет один участник; после загрузки сохраните подтверждение. По предоставленному расписанию дедлайн 16 ноября 2026,18:00 Томск/14:00 МСК.
