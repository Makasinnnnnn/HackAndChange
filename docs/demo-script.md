# Живая демонстрация

Основной адрес: http://localhost:3080. Перед защитой проверить `/api/ready`, убедиться в выбранном режиме и подготовить отдельный браузерный профиль без старых отметок. Синтетический каталог всегда назвать DEMO. Настоящую выгрузку не показывать на публичном сайте.

## 60 секунд

1. «Предпринимателю нужен следующий шаг для конкретной задачи». Нажать «Привлечь клиентов».
2. Показать первый материал, реальное основание рекомендации и следующее действие.
3. Отметить «Изучено», повторить подбор: материал исчезает из выдачи, остаётся в прогрессе.
4. В «Для жюри» выбрать кофейню, сравнить baseline и персональный маршрут, раскрыть факторы. Не выдавать score за вероятность успеха бизнеса.
5. «Прототип работает без API-ключей. Локальная E5 опциональна. Влияние на покупку проверяем A/B-тестом, экспертные метки ещё нужны».

## Полный сценарий, 3–5 минут

| Время | Действие | Ожидаемый результат | Объяснение |
|---|---|---|---|
| 0:00–0:30 | Показать DEMO и задачу кофейни | Один ввод, анкета необязательна | Холодный старт без истории |
| 0:30–1:15 | Получить маршрут и открыть материал | Причины, формат, условия доступа, действие | Польза связана с текущей задачей |
| 1:15–1:45 | Выбрать короткий формат/срочность, пересчитать | Порядок меняется, причины соответствуют данным | Персонализация проверяема |
| 1:45–2:30 | Выбрать предпринимателя в «Для жюри», сравнить | Один запрос и каталог, два настоящих расчёта | Различие алгоритмов видно на кандидатах |
| 2:30–3:00 | Отметить изученное, повторить | Освоенное исключается, прогресс сохраняется | Собственные сигналы работают |
| 3:00–3:30 | Ввести «Помогите с бизнесом» | Уточнение вместо случайной уверенной выдачи | Неполные данные обработаны |
| 3:30–4:15 | Показать FULL локально или агрегаты аудита | 62 таблицы, 102128 строк, 1473 материала после нормализации | Реальная схема исследована |
| 4:15–5:00 | Показать ограничения и A/B-план | Нет выдуманной конверсии или метрик качества | Честный план проверки эффекта |

Запасной сценарий: при отсутствии интернета работает уже собранный локальный стек. При недоступной модели используется лексический поиск. При недоступном источнике показать краткую карточку и честно указать, что полнота ссылок ещё не подтверждена. При реальном сбое API не выдавать скриншот за живую работу: назвать сбой и показать сохранённый PDF как резерв.

Платный материал объясняется кратко, без тела уроков. В DEMO покупка отсутствует. В FULL платный продукт имеет исходные метаданные и ссылку; не обещать доступ или текущую цену сверх выгрузки.
