# Подбор материалов — pipeline v7

Версии: e5-hybrid-personal-v7 / lexical-personal-v7, baseline topic-baseline-v5. Генеративная модель уточняет текст отдельно, не создаёт каталог и не ранжирует материалы.

| Модуль backend/app/recommendation | Ответственность |
|---|---|
| intent.py | Нормализация, конкретная задача, ограничения, сфера и площадка |
| tasks.py | Симптомы пользователя отдельно от свидетельств в title/description; ограниченный неизменяемый кеш |
| eligibility.py | Доступ, формат, отраслевые и предметные конфликты, направление операции до confidence |
| index.py | Word/character TF-IDF, опциональная локальная E5; один индекс каталога |
| ranking.py | Профиль, покрытие составной задачи, разнообразие |
| explanation.py | Причины по фактическим сигналам и предлагаемый следующий шаг |
| policy.py | Веса, пороги, версии |

`engine.py` координирует этот pipeline. Каталог дедуплицируется перед индексацией. Операция должна подтверждаться короткими разрешёнными метаданными, общей тематической метки недостаточно. Явные ограничения и конфликты применяются до ранжирования; профильный бонус не возвращает исключённый материал.

Personal дополнительно исключает completed/known/not_relevant. Неизвестные стадия, уровень или отрасль не дают ложного соответствия. Персональный результат — до трёх сильных карточек; порядок учитывает покрытие разных подтверждённых операций и разнообразие. Отраслево общий результат имеет scope=general и пояснение. При недостатке свидетельств возвращается уточнение, а не случайный хвост.

Лексический сигнал использует word/char TF-IDF. E5 ONNX INT8 работает на CPU локально, query/passage prefixes, masked pooling и нормализация векторов; один encode запроса. Косинус и инженерная шкала score не являются вероятностью релевантности.

Baseline использует тот же каталог и общие ограничения, lexical/topic evidence, без E5, личного профиля/истории и персональных coverage/diversity. Score разных алгоритмов напрямую не сравниваются как метрики качества. Причины строятся только из использованных признаков; предлагаемый следующий шаг не обещает неизвестного содержания урока.

Словари операций и пороги — эвристики; понимание любой формулировки не гарантируется. Qwen получает только текст задачи, предложение проходит проверку ограничений и применяется пользователем явно.
