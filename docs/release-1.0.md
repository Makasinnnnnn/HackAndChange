# Версия 1.0.0

13 ноября 2026. Конкурсный локальный прототип трека 1 Hack&Change, не официальный продукт Альфа-Банка.

Включены: автономный DEMO, закрытый FULL-импорт, профиль/задача, baseline и персональный маршрут, причины и следующий шаг, сохранение прогресса, E5, подключаемый генеративный AI с подтверждением, desktop/mobile UI, Docker и CI. Ключ или модель для базового запуска не нужны.

Новый Q&A учтён: цена NULL курса не отменяет подписку, бесплатность статьи определяется типом, RecommendedItems не является эталоном качества. FULL: 1473 после дедупликации, версия d763cb827e1e1eb8. Пул оценки E5 v3: 32 профиля, 412 пар, 0 человеческих меток.

Проверки: 45 pytest с настоящими весами E5, ruff, frontend typecheck/build. Повторные 8 E2E и реальный Qwen через web API прошли; полный CI dd565f9 прошёл, новый release CI выполняется. Результаты CI для конкретного SHA проверяйте на вкладке Actions. Дамп, веса, каталог и исходные приложения исключены из Git и Docker context. ZIP формируется из committed tree.

Ограничения: человеческая оценка и бизнес-эффект отсутствуют; 507 URL неизвестны, HTTP-проверка блокируется TLS сайта, поэтому ссылки не объявляются проверенными. Реальная история не привязана к сессиям. Qwen 1.5B реально проверен на Windows CPU; три ответа 0.9–1.9 s, это не метрика качества. Веса не входят в архив. Презентация остаётся репетиционной по решению владельца. Публикация версии не является сдачей или публичным деплоем.
