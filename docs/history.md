# История обучения

В «Мой прогресс» можно импортировать JSON с завершёнными курсами. Это явный выбор файла владельцем браузерной сессии, не автоматический вход в чужой аккаунт. Другие отметки сохраняются; импорт идемпотентен. Материалы, отмеченные completed, исключаются из следующей персональной выдачи.

Формат: объект catalog_version (16 hex-символов из GET /api/ready) и completed_material_ids (1–100 уникальных ID курсов текущего каталога). Неверная версия даёт 409, неизвестный материал/не курс/дубликаты — 422 без частичной записи. Нет полей имени, email, исходного UserId или данных платежа. API POST /api/history/import работает только с текущей cookie-сессией.

Локальное воспроизведение реального обезличенного сценария: `python scripts/export_history.py --case-index 0`. Скрипт проверяет метки аудиторского контейнера, использует READ ONLY и statement_timeout. Берёт только завершённые курсы CourseUserBindings, не читает IP, тексты, контакты или покупки; UserId используется для группировки внутри SQL и не экспортируется. Оставляет только ID курсов нормализованного каталога. Файл .private/history-case.json не публиковать. Это исторический сценарий для проверки прототипа, а не история конкретного посетителя. В пользовательском интерфейсе импортировать только свою историю или явно обозначенный тестовый сценарий.

На реальном сценарии проверено 18 завершённых курсов: API принял файл, прогресс сохранился, ни один из них не вошёл в последующую персональную выдачу. Desktop/mobile E2E проверяют импорт и сохранение после reload. Настоящая авторизация Альфа-Курса и проверка владения платформенным аккаунтом потребуют отдельной интеграции при внедрении.
