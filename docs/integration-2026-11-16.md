## Исправления при интеграции

- URL-валидатор отвергает даже пустые учётные данные (`https://@…`); некорректный IPv6 URL не обрушает импорт. Добавлены отрицательные проверки.
- Новый CSV-оценщик PR #2 исправлен: пустая выдача решения остаётся нулевым результатом; явно отрицательные метки учитываются; неразмеченный пул пропускается целиком для обеих систем; конфликт меток и повтор query_id — ошибки. Precision@k использует фиксированный k; IDCG учитывает известный релевантный пул, а не длину ответа. Пустой baseline явно отмечается `baseline_captured=true`; отсутствие capture не подменяется нулём.
- Подробный CSV-отчёт сохраняется только в `.private/` и не перезаписывает предыдущую работу. Out-of-scope ответы учитываются отдельно, включая ошибочную непустую выдачу. Наличие CSV не удостоверяет автора меток.
- `audit/` включён в Ruff CI; добавлены синтетические тесты оценщика и локальные правила `audit/AGENTS.md`. Основной градуированный оценщик `scripts/evaluate.py` сохраняется отдельно; его метрики не смешиваются с бинарным CSV.
- Жёсткие ограничения, защита от отраслевых подмен и baseline не ослаблены по непроверенным предложениям аудита. E5/Qwen остаются опциональными; новые модели/платные API не добавлены.

## Что не считается завершённым

Независимые человеческие оценки, доказанное превосходство, A/B-эффект и проверка всех внешних страниц отсутствуют. Старые 150/120 запросов — использованная при настройке регрессия. Публикация GitHub-релиза не означает отправку в личный кабинет организаторов. Фактические результаты объединённого прогона — в STATUS и release-1.2.4.
