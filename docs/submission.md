# Комплект для сдачи

Трек 1 Hack&Change 2026. Технический комплект подготовлен; фактическую отправку выполняет владелец. Ориентир дедлайна из предоставленного ТЗ: 16 ноября 2026, 14:00 МСК / 18:00 Томск.

## Фиксация после отправки

Уточнение организаторов message994 из экспорта 14 ноября: после отправки улучшения только в отдельной ветке, не main. Подготовка релиза не является отправкой. Перед ручной сдачей выбрать проверенный опубликованный тег и записать точную версию:

```powershell
python scripts/submission_snapshot.py --ref v1.2.2
```

Замените тег на выбранный финальный релиз. Команда читает файлы именно тега, проверяет VERSION и сохраняет commit и SHA-256 PDF/PPTX в игнорируемую `.private/submission/`. Уже существующую запись не перезаписывает; ничего не отправляет и не включает защиту Git. Владелец отдельно фиксирует дату и подтверждение фактической отправки. После этого main и отправленный тег не менять; новые изменения — в `post-submission/...`. При работе с другим клоном также соблюдать это правило: локальная запись не является серверной защитой ветки.

В экспорте message1033 формат отправки обещан отдельным постом, самого поста ещё нет. Финалистов обещают объявить 20 ноября вечером, онлайн-финал — 22 ноября. Проверить новый официальный пост перед отправкой.

## Как жюри запускает

Нужен Docker Desktop с Linux containers. В распакованном корне проекта:

```powershell
docker compose up --build
```

Открыть http://127.0.0.1:3080 . Это DEMO на 36 авторских примерах, без API-ключей, закрытого дампа и загрузки моделей. Первая сборка требует доступа к публичным реестрам Docker/npm/PyPI. Если порт занят, в PowerShell перед запуском: `$env:WEB_PORT='3082'`, затем открыть соответствующий порт.

FULL с данными организаторов запускается только локально по README через отдельный импорт и `compose.full.yaml`. E5 и Qwen опциональны; веса не входят в архив. Во время демонстрации явно различать синтетический DEMO и реальный FULL.

## Короткий показ

1. Выбрать стартовую задачу или ввести свою; профиль можно пропустить. Построить маршрут.
2. Показать причину, предлагаемый следующий шаг и источник материала. Не утверждать неизвестную цену/длительность/URL.
3. Отметить «Изучено» или «Не подходит», перестроить и показать исключение; прогресс сохраняется после перезагрузки.
4. На экране «Для жюри» сравнить два фактических расчёта на одном каталоге. Большее внутреннее score не является метрикой качества.
5. При подключённом Qwen показать предложение, уточнение и явное применение. Без Qwen основной сценарий работает.
6. Показать честное уточнение для постороннего запроса и общий характер подборки при отсутствии отраслевого материала.
