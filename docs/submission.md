## Что показать

1. Свободный ввод задачи без обязательной анкеты → маршрут, объяснение и следующий шаг.
2. FULL: официальный источник, отдельное описание и обозначение платного доступа; DEMO: авторский учебный пример.
3. «Изучено»/«Не подходит» → перестроить → исключение материала; сохранение прогресса после перезапуска.
4. Сравнение baseline и personal на одинаковом каталоге; оно допустимо и в презентации. Внутренний score не является метрикой качества.
5. Неизвестная задача → уточнение; общий/неполный результат явно обозначен.
6. Опциональный Qwen → предложение с явным принятием; без LLM основной подбор работает.

Проверки версии:182 Python с E5,46 браузерных сценариев, production Docker, FULL/DEMO smoke и persistence. Подробности STATUS. Независимые человеческие метки отсутствуют; нельзя заявлять измеренный рост конверсии или превосходство.150/120 запросов — использованная при настройке регрессия. Все внешние страницы не проверены.

## Фиксация и отправка

До ручной загрузки выбрать опубликованный проверенный тег:

```powershell
python scripts/submission_snapshot.py --ref v1.2.4
```

Команда сохраняет commit и SHA-256 в `.private/submission/`, ничего не отправляет и не защищает серверную ветку. После загрузки владелец сохраняет подтверждение и время. После фактической отправки main и отправленный тег не менять, улучшения — `post-submission/...`. Официальный пост также фиксирует версию после дедлайна.
