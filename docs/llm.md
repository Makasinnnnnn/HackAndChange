# Подключаемый AI-помощник

Базовый стек не вызывает генеративную модель. Дополнительный `compose.llm.yaml` включает совместимый Chat Completions endpoint: локальный Ollama либо HTTPS API. Реализация протокола сверена с официальной документацией: https://github.com/ollama/ollama/blob/main/docs/api/openai-compatibility.mdx .

В .env задайте LLM_MODEL (точное имя уже установленной локальной модели, например своего Qwen). Для Ollama на Windows используется LLM_BASE_URL=http://host.docker.internal:11434/v1 и LLM_MODE=local. Запуск: `docker compose -f compose.yaml -f compose.llm.yaml up -d --build`. Если используется E5, добавьте также `-f compose.semantic.yaml`. Модель должна быть доступна из Docker; никаких скачиваний весов при старте приложения нет. Cloud-суффикс в локальном режиме запрещён. Установка и реальный inference Qwen пока не проверены; совместимость конкретной модели с JSON mode требует проверки.

Для совместимого API предусмотрены LLM_MODE=api, LLM_BASE_URL=https://.../v1, LLM_MODEL, LLM_API_KEY и явный LLM_ALLOW_EXTERNAL=true. Это конфигурация оператора, не браузера. Ключи только в исключённом .env, никогда в UI или Git. Внешний API не включён и реальные внешние запросы не выполнялись. Запрос может содержать персональные сведения: до внешнего включения нужен отдельный этап минимизации/редактирования данных. Свой ключ ассистент не предоставляет.

Модель получает только текст задачи (до 1500 символов); каталог, профиль, история и закрытые уроки не отправляются. Ответ проходит строгую схему goal/clarification, лишние поля отклоняются. Нет выполнения инструментов, команд, HTML или предложенных моделью ссылок. Сгенерированный текст отображается штатным экранированным UI. Он является предложением формулировки, а не доказанным пониманием намерения пользователя.

Первая итерация намеренно не меняет ранжирование текстом модели: сохраняет исходную задачу и добавляет предложение формулировки в notice. Уточняющий вопрос применяется только при пустой выдаче. Следующая итерация — подтверждение пользователем новой формулировки и независимая проверка качества. При таймауте (8 секунд), неверном JSON, слишком большом ответе или недоступности сервера остаётся обычный маршрут с уведомлением. Перенаправления HTTP запрещены. Локальный режим допускает только фиксированные имена loopback/host Docker, API — HTTPS с отдельным включением.

Проверены выключенный режим, блокировка удалённого адреса в local, необходимость включения api, валидный ответ и неверная схема через контролируемый транспорт. Это не проверка реального Qwen и не замер качества.
