# AI-адаптер

Точные команды модели и runtime, контрольные суммы и `.env` находятся в разделах 5/8/9 [инструкции](../START_HERE_JURY.md). Проверенный native-вариант: Windows llama.cpp b7200, Qwen2.5-1.5B-Instruct GGUF Q4_K_M, loopback18080. E5 — отдельная модель поиска, не генеративный помощник.

POST `/api/intent` вызывается отдельной AI-кнопкой. Адаптер Chat Completions передаёт только введённый текст задачи, не каталог/историю/профиль. Ответ — схема goal/clarification; неизвестные поля и некорректные ответы отклоняются, HTML не исполняется. Явные ограничения исходного запроса сохраняются. Применение предложения требует действия пользователя.

Режим по умолчанию off. Локальный режим разрешает фиксированные локальные имена HTTP, cloud-модели блокируются. Внешний режим требует HTTPS и явного LLM_ALLOW_EXTERNAL=true; ключ хранится у оператора. Текст может содержать ПДн — до внешней передачи требуется разрешение и минимизация. Платный провайдер не включён и не требуется.

Статусы: disabled, model_missing, configuration_blocked, invalid_configuration, unavailable, invalid_response, unchanged, ready. Таймаут и невалидный ответ не блокируют обычный подбор. Bootstrap llm_enabled означает конфигурацию; фактическую доступность подтверждает запрос `/api/intent`.
