Онлайн: 30% работоспособность, 25% качество, 20% архитектура/документация, 15% персонализация/неполные данные, 5% объяснимость, 5% презентация (PDF, с. 13). Финал: 25/25/20/15/10/5%, вес этапов по 50%.

Важно: Next.js, embeddings, 30–50 профилей, автономное demo и красивый fintech UX — решения команды/владельца, а не жёстко заданный стек PDF. Telegram, напоминания и банковские интеграции не требуются для выбранного трека.

Сдача: PDF со ссылкой на репозиторий на первом слайде **или** ZIP с кодом, документацией и PDF (с. 9). Для приватного репозитория дать доступ `hack-and-change-2026`. Репозиторий публичный; по прямому поручению владельца версия 1.0 опубликована в main и теге v1.0.0. GitHub Release содержит публичный ZIP и SHA-256. Публикация исходников не является сдачей организаторам.
