# Скрипты — дополнение к корневому AGENTS.md

Прочитать `../AGENTS.md`, README и описание используемого скрипта. Запускать из корня репозитория. Перед изменением CLI проверить его `--help` и реальные вызовы в документации/CI.

- Импорт, аудит и извлечение ссылок выполняются локально с закрытыми данными. Результаты реального каталога, SQL, модели, история и подробные выдачи — только `.private/`; не публиковать их как fixtures.
- Source DB читать без изменения таблиц. Восстановление только в явно выделенную аудиторскую БД; проверять метки project/purpose, отсутствие внешних портов и network=none. Не затрагивать рабочий PostgreSQL и чужие тома.
- Не отключать TLS и не считать timeout/ошибку сертификата доказательством мёртвой ссылки. У проверок сети должны быть таймауты, умеренный темп и остановка на rate limit.
- `audit_recommendations.py` записывает фактические ответы в новый приватный файл; `--suite natural` — 150 авторских регрессионных запросов. Не выдавать эти оценки за человеческие/независимые.
- `evaluate.py prepare/calculate`: не перезаписывать разметку, не переносить labels между несовместимыми версиями. Для human-метрик нужны label_source=human и автор оценки. Отсутствие меток даёт metrics=null.
- `package_release.py` упаковывает закоммиченный публичный HEAD. Сначала проверить staged diff, `check_public_files.py`, `check_version.py`; существующие архивы не заменять.
- `submission_snapshot.py` готовит запись выбранного тега для ручной сдачи. Не считать её отправкой или автоматической защитой main.
- Платный inference или переход на платную модель без решения владельца запрещены. Бесплатность внешнего помощника проверять заново; закрытые данные ему не передавать.

После изменения Python-скриптов: из корня `ruff check backend scripts` и подходящая проверка CLI на синтетическом/изолированном примере. Не запускать restore/import/download ради формальной проверки документации.
