# Frontend — дополнение к корневому AGENTS.md

Прочитать `../AGENTS.md` и `../docs/TEAM.md`. Next.js App Router: `app/page.tsx` — основные сценарии, `app/globals.css` — оформление, небольшие компоненты находятся рядом. Проверки — `tests/journey.spec.ts`; конфигурация — `playwright.config.ts`.

- Сохранять API-контракт: `query`, nullable-поля профиля, `match_scope`, `clarification`, `notice`, `reasons` и `next_action`.
- Не имитировать рекомендации/метрики/AI на клиенте. Изменение задачи, профиля или feedback должно явно помечать прежнюю подборку; запоздалый ответ не заменяет новый. Ошибка AI не блокирует обычный подбор.
- Пользователь явно принимает AI-формулировку и импорт истории. Не терять исходный текст, ограничения, прогресс и контекст при навигации/ошибке. Не требовать обязательной анкеты или AI API.
- Проверять клавиатуру, подписи, возврат фокуса, мобильное меню, ошибки, загрузку и отсутствие горизонтального скролла. Не прятать объяснение общего/неполного совпадения.
- Не показывать служебные веса и сырые поля БД в основном пользовательском сценарии. Диагностика для жюри отделена от обычных карточек.
- Использовать существующие компоненты и локальные assets/шрифты. Новые библиотеки и полную замену дизайна не добавлять попутно.
- Для публичных снимков использовать `tests/capture.mjs` только с отдельным DEMO. Реальные FULL-карточки и пользовательские сведения не включать в `docs/screenshots/` или презентацию.

Из `frontend/`: `npm run typecheck`, `npm run build`, `npm run test:e2e`. E2E выполнять против отдельного DEMO через E2E_BASE_URL: они сохраняют feedback и импортируют синтетическую историю. Не запускать их против рабочего FULL/сессии владельца. Изолированный запуск описан в TEAM.
