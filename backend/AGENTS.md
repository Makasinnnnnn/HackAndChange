# Backend — дополнение к корневому AGENTS.md

Прочитать `../AGENTS.md` и `../docs/recommendation-pipeline.md`. API-контракт и модели — `app/main.py`, `app/models.py`; сессии и прогресс — `app/storage.py`.

## Где менять подбор

- `app/recommendation/intent.py`: нормализация запроса, ограничения, неоднозначность.
- `tasks.py`: пользовательские симптомы отдельно от свидетельств в title/description; не привязывать к ID реального каталога.
- `eligibility.py`: доступность, предмет, направление, формат, отраслевые конфликты и ограничения до confidence.
- `index.py`: TF-IDF и опциональная E5; индекс каталога строится один раз, query embedding — один на запрос.
- `ranking.py`: порядок, разнообразие, покрытие разных частей задачи.
- `explanation.py`: объяснения и следующий шаг по фактическим сигналам; неизвестное содержание урока не обещать.
- `policy.py`: веса, пороги, версии personal/baseline.
- `app/engine.py`: оркестрация; не складывать сюда проверки отдельных пользовательских фраз.

Изменение смысла подтверждать отрицательным примером и положительным контрольным запросом. Не исправлять подбор добавлением конкретного source ID или заголовка из дампа. Кеши должны быть ограниченными и возвращать неизменяемые значения.

Не заполнять выдачу до фиксированного числа слабым материалом. До трёх сильных персональных карточек, допустимы одна карточка, пробел и уточнение. Составную задачу покрывать разными подтверждёнными операциями. General scope определяется по показанным карточкам.

Сохранять изоляцию cookie-сессий, явный импорт истории и исключение known/completed/not_relevant. Не связывать посетителя с исходной историей автоматически. Импорт и каталог не должны раскрывать платные тела/ПДн.

`app/llm.py`: строгий разбор ответа, ограничения/таймауты, запрет незаметной внешней передачи и сохранение явных условий пользователя. Не переносить выбор материалов в свободную генерацию.

Из корня: `python -m pytest -q`, `ruff check backend scripts`. Новый баг проверять синтетическими fixtures, не копией дампа. Для реальной E5 нужен локальный путь TEST_SEMANTIC_MODEL_DIR; без весов соответствующая опциональная проверка пропускается. API/хранение дополнительно проверять `python scripts/smoke.py` на своём тестовом экземпляре.
