# Аудиты — дополнение к корневому AGENTS.md

Материалы PR #2 описывают исторический DEMO-аудит; актуальные решения и проверки — в `../docs/STATUS.md` и `../docs/integration-2026-11-16.md`. Приоритеты автора аудита не становятся требованиями организаторов или разрешением убрать фильтры.

- Публичны только методика, код и авторские синтетические примеры. Заполненный CSV, реальные capture и подробный отчёт хранить в `.private/`.
- Пустые метки означают отсутствие оценки; пустая выдача не должна исчезать из измерений. Сравнивать системы на одинаковых полностью размеченных пулах.
- Примеры, известные разработчикам, не являются независимым holdout. CSV сам по себе не подтверждает человеческое происхождение меток.
- Не переносить гипотезы DEMO на FULL без проверки и не публиковать source ID/выдачи реального каталога.

После изменения оценщика: `ruff check backend scripts audit`, `pytest -q backend/tests/test_blind_eval.py`. Основная градуированная оценка продукта остаётся в `scripts/evaluate.py`.
