# Данные и сообщения об уязвимостях

Прототип предназначен для локального запуска. По умолчанию доступен только на 127.0.0.1, API и PostgreSQL не публикуют порты. Пароль DEMO предназначен для локального окружения. Для внешнего размещения нужна отдельная проверка конфигурации.

Не публикуйте уязвимость вместе с персональными данными, токенами, дампом или реальными строками каталога. Используйте приватное сообщение владельцу репозитория либо GitHub private vulnerability reporting, если оно включено. Автоматической гарантии защиты и полного security-аудита нет.
