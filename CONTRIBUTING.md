# Работа с проектом

Начните с AGENTS.md и docs/STATUS.md. Изменения делайте законченными итерациями. Запуск: README.md. Backend: pytest и ruff; frontend: typecheck, build и E2E с запущенным Docker. Для реальной E5 укажите TEST_SEMANTIC_MODEL_DIR. Перед commit запустите scripts/check_public_files.py.

Дамп, метаданные организаторов, реальные профили, переписка, модельные веса, ключи и локальная БД не должны попадать в Git или образ. Синтетические данные явно помечаются. Не меняйте исходную аудиторскую базу. Не публикуйте метрики без происхождения оценок. Правила лицензирования сторонних моделей не распространяются автоматически на код проекта.
